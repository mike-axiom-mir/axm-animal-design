# Technical Art direction-frame reconstruction contract

This contract adopts one bounded receiving option from Rigging's retained post-skin owner-frame reconstruction evidence without changing the historical transport finding.

The exact static `NORMAL` / `TANGENT` payload in the retained Animal GLB remains unsuitable as a deformed owner direction frame when it is simply skinned. The adopted option instead treats the already-green skinned `POSITION` field as the receiver input, requires the fixed Geometry render-to-source mapping/topology/UV/tangent-handedness identities, and delegates owner-frame reconstruction to the domain-owned Rigging/Geometry implementation.

Technical Art owns only the integration contract and its fail-closed evidence gate. It does not copy the owner reconstruction algorithm. Universal Creation remains the unchanged generic rigged-GLB transport receiver and receives no Animal topology, UV, rig, anatomy, weighting, or reconstruction policy.

A contract PASS means the exact owner evidence is strong enough for a target implementation to consume this recipe. It does not mean a target engine, shader, runtime, controller, or device already implements it. Runtime implementation, target-engine proof, shaded appearance acceptance, CANON, and production readiness remain separate gates.

The four AXM roots — Truth, Agency / non-domination, Continuity, and Wisdom before speed — remain the merge gate.
